# deep4+12-rezero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Function-preserving trunk growth (4 anchor blocks + N ReZero blocks), resumable training state, and an exact-semantics collection benchmark — so the ratified 260-iteration capacity lap can launch, survive restarts, and deploy a winner unchanged through B2c serving.

**Architecture:** `growth_blocks` is a dormant-at-0 ModelConfig field (B2b pattern: default 0 ⇒ state_dict byte-identical). Growth blocks are `x + alpha·F(x)` with scalar `alpha=0` init in a SEPARATE `growth.*` key namespace, so anchor tensors load verbatim and step-0 outputs are exactly the anchor's. Loading stays metadata-authoritative with a state-dict-derivable growth count checked pre-construction.

**Tech Stack:** Python 3.12 (`ai/` only — no Go changes). Spec: `worklog/specs/2026-07-24-deep16-rezero-design.md`. Branch: `claude/deep16-rezero` (off main @ 186c300, spec commit 402bda0).

## Global Constraints

- `growth_blocks=0` ⇒ `PolicyValueNet.state_dict()` byte-identical to today (marshal test required).
- Step-zero invariant: grown net's logits, value, Q, aux outputs, and greedy actions EXACTLY equal the anchor's (`torch.equal` / argmax identity).
- Growth keys namespace: `growth.{i}.…` and `growth.{i}.alpha`; legacy namespace untouched.
- `growth.*` keys without usable metadata ⇒ fail-closed load (same policy as B2b keys); bounds enforced in `ModelConfig.__post_init__` before any allocation.
- Recipe knobs are NOT touched: no changes to lr/ppo/gamma/entropy/matches-per-iter paths.
- Full `uv run --project ai pytest -q` green before each commit; commits end with: `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`
