# PR 3 — Go De-duplication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the duplicated Go code identified as Tier 1 in §7.1 of the design doc, without
changing any behaviour the engine, API, or RL bridge produces.

**Architecture:** Extract each duplicated unit into the package that already owns the concept
(`internal/engine`, `internal/rl`, `internal/bot/remote`, `internal/storage`), rewrite call sites
one at a time, delete the copies. Test-fixture duplication is consolidated first — it is the
lowest-risk half and makes the production extractions easier to verify.

**Tech Stack:** Go 1.25, protobuf, Gin, gorilla/websocket, GORM.

**Spec:** `worklog/specs/2026-08-16-dedup-and-naming-refactor-design.md` §7.1
(that file lands with PR #210; this branch is cut from `main` so the Go work can merge independently).

## Global Constraints

- **Behaviour-preserving only.** Same inputs → same outputs. No proto changes, no wire-format
  changes, no new dependencies.
- **Architecture invariants that must survive:**
  - `internal/engine` must **never** import `internal/rules`.
  - `internal/engine` deliberately does **not** depend on `internal/tiles`.
  - `internal/review` must not import `internal/api` (would cycle).
  - `ai/events.py` mirrors `internal/rl/eventcodec.go` — **change both or neither.** This PR
    changes neither.
  - Scoring entries only via `rules.NewScoreEntry`; never rename a `pattern_id`.
- **Gate after every task:** `gofmt -l .` (must print nothing), `go vet ./...`, `go test ./...`.
  Baseline: all packages ok.
- **Differential harness before the PR opens** (see Task 10): seeded `cmd/rlpaipu` output must be
  byte-identical to the golden files captured from `main`.
- **Commit per task.** Update each touched package's `CLAUDE.md` in the same commit.
- Splitting a file? Do the `git mv` in its own commit first — see `docs/refactoring-notes.md`,
  PR 2, for why.

- [ ] **Step 2:** Extract `FinalScores` alone first (a pure duplicate). Gate.
- [ ] **Step 3:** Extract `DriveHeuristic`; convert `cmd/rlpaipu` first, then **re-run the differential harness** — the paipu output must stay byte-identical.
